# 👗 MyCloset

所有している洋服を管理し、購入金額や買い物傾向まで分析できるWebアプリケーションです。


職業訓練校での学習成果として、企画・設計・実装・テストまで一貫して制作しました。

---

## 📖 概要

クローゼットの洋服をデータベースで管理し、登録・検索・分析ができるWebアプリケーションです。

洋服を管理するだけでなく、購入金額をカテゴリ別・季節別に分析できる機能を実装し、「どの季節・カテゴリにお金を使っているか」を把握できるようにしました。

## ✨ 主な機能

- 洋服情報の登録・削除
- 洋服画像のアップロード
- トップページでの洋服一覧表示
- 洋服カードをクリックした際の詳細画面表示
- カテゴリ・カラー・季節・お気に入りによる複数条件検索
- お気に入り登録・解除
- 売りたいリストの作成
- カテゴリ別・季節別の分析（グラフ表示）

---

## 💡 工夫した点

- 洋服を管理するだけでなく、購入金額をカテゴリ別・季節別に分析できる機能を実装し、自分の買い物傾向を把握できるようにしました。
- 「春のトップスにいくら使ったか」など、カテゴリと季節を組み合わせて分析できるようにし、自分のお金の使い方を振り返りやすい設計にしました。
- 複数の検索条件を組み合わせることで、目的の洋服を探しやすい仕様にしました。
- トップページでは洋服をカード形式で一覧表示し、カードをクリックすると詳細画面でブランド・カラー・価格・季節・お気に入り状況などを確認できるようにしました。
- 洋服カードにカーソルを合わせると少し浮き上がる動きを付け、操作した際に変化が分かりやすく、親しみやすい画面を意識しました。
- 実際に何度も操作を繰り返しながら、レイアウトやボタン配置など、見やすさ・使いやすさを改善しました。
